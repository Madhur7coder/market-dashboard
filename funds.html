Notes. NAVs are end-of-day, fund-currency-native (no FX adjustment). Primary source is Yahoo Finance via yfinance (free, no API key); Financial Times markets.ft.com historical pages serve as fallback for funds yfinance doesn't cover with a daily series. 1D, 1W, MTD are computed from the most recent NAV vs. previous trading day / 5 trading days back / last trading day of previous month. YTD uses the close of the last trading day of the previous calendar year. 1M / 3M / 6M / 1Y are calendar-date-based (look back ~30 / 91 / 182 / 365 days). Funds marked — ISIN MISSING need an ISIN added to funds.json; — DATA UNAVAILABLE means neither yfinance nor FT could return a series. Refresh: auto-fetched weekday post-close (~17:00 EST) by GitHub Actions, same schedule as the main dashboard.
